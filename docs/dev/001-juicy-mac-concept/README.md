## Идея

Juicy Mac — нативный центр управления MacBook в menubar. Он показывает, сколько «сока»
осталось у машины: заряд, CPU, память, диск, температуры, вентиляторы. Когда что-то идёт не так,
он подсказывает причину и умеет вмешаться: раскрутить вентиляторы, предупредить, назвать виновника.

Метафора сквозная:

- **Стакан сока** — иконка в menubar. Уровень сока равен заряду, пузырьки поднимаются во время зарядки.
- **Сок** — ресурсы машины. «Thirstiest apps» — самые прожорливые процессы.
- **Вкусы (Flavors)** — темы: Orange, Lime, Grape, Cherry, Blueberry и Ripe (цвет меняется с зарядом).
- **Juice score** — одна цифра здоровья Mac от 0 до 100.

Визуальный язык: macOS 26+ Liquid Glass. Полупрозрачные стеклянные панели с бликом по краю лежат
поверх цветного градиентного фона. У каждого модуля свой цвет, как в CleanMyMac. Иконки объёмные,
глянцевые, свои, отрендерены в Blender. Готовые наборы иконок не используются.

## Для кого

- Разработчики и креаторы, которые гоняют Mac под нагрузкой (сборки, рендер, ML) и хотят видеть, что происходит.
- Владельцы MacBook, которых волнуют здоровье батареи, нагрев и шум.
- Все, кому нравятся красивые утилиты в menubar.

## Поверхности

### 1. Menubar item
Пять стилей: Glass, Glass + число, Readouts (три метрики в две строки), Pulse (живой график CPU),
Alarm (любой стиль краснеет и показывает причину, когда срабатывает правило).

### 2. Popover (клик по иконке)
Заряд и остаток времени, плитки CPU / Memory / Disk / Heat со спарклайнами, переключатель
вентиляторов Auto / Chill / Blast, топ-3 прожорливых процессов, выбор вкуса, кнопка «Open Juicy Mac».

### 3. Окно приложения
Сайдбар из стеклянной панели: Overview, CPU, Memory, Disk, Battery, Fans, Sensors, Alerts, Flavors.

- **Overview** — Juice score, короткий вердикт человеческим языком, подсказки («Chrome Helper держит
  30%+ CPU 12 минут» → Quit process), четыре карточки-сводки. Кнопка **Squeeze test** запускает
  30-секундный стресс-тест CPU, вентиляторов и нагрева.
- **CPU** — загрузка по ядрам (P/E), частоты, история, процессы.
- **Memory** — pressure, Apps / Wired / Compressed / Cache, swap.
- **Disk** — свободное место по томам, скорость чтения и записи, SMART.
- **Battery** — здоровье, циклы, текущая мощность, лимит заряда (80%), история за 24 ч.
- **Fans** — режимы Auto / Chill / Blast / Custom, редактор кривой «температура → обороты», два датчика оборотов.
- **Sensors** — все доступные температуры и мощности.
- **Alerts** — правила «когда что-то не так»: условие, длительность, действие (раскрутить вентиляторы,
  уведомить, покрасить стакан в красный).
- **Flavors** — темы.

Виджеты WidgetKit, App Intents для Shortcuts, история за 30 дней, экспорт в CSV.

## Как считается Juice score

Взвешенная сумма нормированных показателей со штрафами за устойчивые проблемы:

| Компонент | Вес | Что снижает |
|---|---|---|
| Нагрев | 30% | температура CPU выше 85°C дольше 60 с, троттлинг |
| Память | 25% | memory pressure warn/critical, рост swap |
| CPU | 20% | устойчивая загрузка выше 80% дольше 5 мин |
| Диск | 15% | свободно меньше 10%, ошибки SMART |
| Батарея | 10% | здоровье ниже 80%, аномальный расход |

Веса предварительные, их нужно откалибровать на реальных данных.

## Техника

- **UI**: Swift 6, SwiftUI, `MenuBarExtra(.window)`, `glassEffect()` / `GlassEffectContainer` (macOS 26+),
  Swift Charts. Минимальная версия — macOS 26.
- **CPU**: `host_processor_info` (тики по ядрам), `sysctl hw.perflevel*` (раскладка P/E-ядер).
- **Память**: `host_statistics64(HOST_VM_INFO64)`, `sysctl vm.swapusage`, `DispatchSource.makeMemoryPressureSource`.
- **Диск**: `URLResourceValues.volumeAvailableCapacityForImportantUsage`, счётчики `IOBlockStorageDriver`.
- **Батарея**: `IOPSCopyPowerSourcesInfo` и реестр `AppleSmartBattery` (циклы, ёмкость, мощность).
- **Датчики и вентиляторы**: SMC через IOKit (`AppleSMC`). Чтение работает из обычного процесса,
  запись оборотов требует root: нужен привилегированный хелпер (`SMAppService.daemon`) и XPC
  с проверкой code signing requirement клиента.
- **Процессы**: `proc_pidinfo` / `proc_pid_rusage`.
- **Дистрибуция**: вне Mac App Store (sandbox запрещает SMC и хелпер). Developer ID, нотаризация,
  обновления через Sparkle.

## Риски

1. **Управление вентиляторами на Apple Silicon.** Ключи SMC (`F0Md`, `F0Tg`, разблокировка `Ftst`)
   недокументированы и могут меняться между версиями macOS. Нужны fallback на режим «только чтение»
   и понятное сообщение пользователю.
2. **MacBook Air без вентиляторов.** Модуль Fans заменяется на «Thermal»: троттлинг и советы.
3. **Расход энергии самим приложением.** Опрос раз в 1 с при открытом popover и раз в 5 с в фоне,
   без таймеров, пока экран спит.
4. **Безопасность хелпера.** Минимальный XPC-интерфейс (задать режим и обороты в допустимых пределах),
   автоматический возврат в Auto при падении клиента.
